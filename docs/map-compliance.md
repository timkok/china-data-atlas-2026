# 地图合规决定

决定日期：2026-11-24。V0.1 **不发布任何中国地图**，包括填色的省界图。正式的空间浏览是「分区瓦片 + 排名 + 趋势」，瓦片按七大地理区排列，不按经纬度画边界。

## 查过的规则和来源

- 《地图管理条例》第十五条：向社会公开的地图，应当送审。景区图、街区图、公共交通线路图等简单地图除外。全国地图、跨两个以上省级行政区的地图，由国务院自然资源主管部门审核。
- 《地图审核管理规定》第五条、第六条：直接使用自然资源主管部门提供、且带审图号的公益性地图，可以不再送审，但要标注审图号。已经审过的地图如果内容发生变化后再次公开，需要重新送审。
- 自然资源部地理信息管理司对「能否只改各省填色、沿用原审图号」的公开答复是：填色属于内容变化，公开前要重新送审，通过后核发新的审图号。放大、缩小、裁切同样需要送审。（见自然资源主管部门 2023–2025 年的公开问答，例如广西自然资源厅转载的「中国地图，这样使用才规范」，以及中国测绘学会转载的同一口径。）
- [标准地图服务](http://bzdt.ch.mnr.gov.cn/) 可以免费下载带审图号的标准地图，直接使用并标注审图号。本站需要按指标和年份重着色，这正是答复里认定需要重新审核的改动。本环境不能代为取得审图号。
- 阿里云 DataV GeoAtlas 的说明写明数据来自高德开放平台，仅供学习交流，不能当作已审核的标准地图。

## 因此不发布的内容

不使用标准地图改色，不使用 GeoAtlas / 其他公开 GeoJSON 画省界，不画南海诸岛、九段线或台湾的示意轮廓。不把「看起来像地图」的变形网格当成合规替代。

瓦片没有海岸线、没有国界、没有行政界线。它表示的是「这个省在这个指标上的数值」，分组名称（华北、东北、华东、华中、华南、西南、西北）在关于数据页写明成员，并与国家统计局东、中、西、东北的经济区域分开，避免两套分组混用。内蒙古在七区里属华北，在统计局四区里属西部。

若以后取得覆盖「按数据重着色的全国分省图」的审图号，再把地图加回指标页，并在图下标注审图号。在那之前，排名和瓦片是正式功能，不是占位。
